# 个人作品集 · 小和

一个面向老师、同学与企业招聘人员的个人作品集网站，用于展示个人介绍、技能方向与项目作品。

采用现代极简的「**左侧固定介绍栏 + 右侧主内容区**」双栏布局，桌面端左右分区、移动端自动切换为上下布局；整体为浅蓝色清爽视觉风格，并**支持深浅色主题一键切换**。

## 核心功能

- **个人展示**：左侧栏集中展示头像、姓名、简介、技能方向（编程语言 / 关注方向）与站点导航，保持稳定、随内容自然浏览。
- **项目作品**：纵向分栏展示多个项目，每个项目包含名称、完成时间、类别、技术栈、项目简介，以及核心功能 / 我的工作 / 成果 / 技术要点等可选字段；项目数据集中在 `js/main.js` 的数组内，**新增项目仅需追加一条数据，无需改动 HTML**，便于持续扩展。
- **关于我 / 联系方式**：个人介绍与邮箱、微信、GitHub、所在地、个人主页等联系方式。
- **滚动高亮导航**：随内容滚动自动高亮左侧当前区块。
- **🌓 深浅色主题切换**：
  - 右上角固定圆形按钮，一键在浅色 / 深色主题间切换；
  - 图标随主题在「月亮 / 太阳」间平滑过渡；
  - 页面背景、面板、文字、边框、标签等全部颜色通 CSS 变量实时联动变化；
  - 选择结果通过 `localStorage` 持久化，再次打开自动恢复上次主题；首次访问遵循系统 `prefers-color-scheme`。

## 技术栈

- **纯原生 HTML / CSS / JavaScript**，无任何前端框架，无第三方 UI 组件库，无新增依赖。
- 布局：CSS Grid 双栏 + `position: sticky` 固定侧栏 + 媒体查询响应式（`@media (max-width: 920px)` 切换为上下布局）。
- 主题：CSS 自定义属性（`--bg`、`--text` 等变量）+  `[data-theme="dark"]` 覆盖 + JS 切换。
- 项目渲染 / 导航高亮：原生 DOM 操作。

## 目录结构

```
├── index.html        # 页面结构：侧栏(介绍/技能/导航) + 主内容(作品/关于/联系)

│   └── main.js       # 项目数据与动态渲染、主题切换、滚动导航高亮

└── .gitignore
```

## 本地运行

项目为纯静态站点，无需安装依赖。任选其一：

**方式一：直接打开**
双击 `index.html` 用浏览器打开即可。

> 注意：项目配图使用在线生成接口，需联网加载；跨域限制可能导致个别 `file://` 情况下异常，推荐方式二。

**方式二：本地静态服务器（推荐）**

```bash
# 项目根目录下执行
python -m http.server 8080
```

浏览器访问 `http://localhost:8080/`。

或使用 VS Code / Trae 的 Live Server 插件直接预览。
